# Trip Insights — CarPlay trip timer

A free iPhone trip timer with a CarPlay widget, stop tracking, pause/resume, reconnect grace periods and trip history.

- [View on the App Store](https://apps.apple.com/app/id6829318971)
- [Website and setup guide](https://rayan65.github.io/triptime-support/)
- [Privacy Policy](https://rayan65.github.io/triptime-support/privacy.html)
- [Launch copy and product facts](launch-kit.md)

Automatic timing requires two personal automations in Shortcuts. CarPlay widgets require iOS 26 or later and a compatible CarPlay display.

This repository contains the public website and product copy only. The app source is private.
